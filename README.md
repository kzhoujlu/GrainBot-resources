# GrainBot Resources

Versioned model adapters, model weights, and data-only datasets for GrainBot.

## Current resource release

[GrainBot Resources 2026.10.14.resources1](https://github.com/kzhoujlu/GrainBot-resources/releases/tag/2026.10.14.resources1)

- Signed EMPS BPartIS adapter with separately acquired official code and weights.
- Signed Prior-Guided SEM material-phase and grain-boundary datasets.
- Signed UO2 SEM-BSE dataset, four separate official checkpoints, and implementation archive.
- Signed TBM benchmark dataset; existing training exclusion remains in force.
- Official-source entries for Patrick BF-TEM and original GrainBot/GrainBot-V2 resources.

[Machine-readable resource catalog](https://github.com/kzhoujlu/GrainBot-resources/releases/download/2026.10.14.resources1/resource-catalog.json) | [Catalog signature](https://github.com/kzhoujlu/GrainBot-resources/releases/download/2026.10.14.resources1/resource-catalog.sig) | [Integration contract](https://github.com/kzhoujlu/GrainBot-resources/releases/download/2026.10.14.resources1/INTEGRATION.txt)

Verify signatures using a separately trusted release public key and check SHA256 before installation. Each item preserves its own upstream license, attribution, and review status; this repository does not replace third-party license terms. Assets with unverified redistribution terms are linked to their official sources without mirroring raw files.

Application packages are published separately in [GrainBot-distribution](https://github.com/kzhoujlu/GrainBot-distribution/releases/tag/2026.10.14.post2). Installer executables and Python runtimes are not distributed here.
