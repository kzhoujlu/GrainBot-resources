## Source and annotation relationships

- **316L Artificial and Real Grains:** 480 real RG crops and 800 synthetic AG images. The eight-image demonstration subset overlaps this source; seven selected fields belong to the retained model training split and one to its test split. Demonstration metadata now disables training and does not claim sealed evaluation.
- **ExONE 316L:** 336 crops from 21 fields. The full-field expert-review collection is derived from these crops and retains weak reference labels pending human review.
- **Prior-Guided SEM:** the material-phase and grain-boundary snapshots share 82 original images; their two label tasks do not represent 164 independent source images.
- **GrainBot-V2 SEM:** Type 1 and Type 2 each contain eight images. The combined set contains those same 16 images. The primary pore masks are derived weak labels generated by intensity and geometry rules; they are not original human pore ground truth. Auxiliary grain-boundary labels are preserved separately.
- **Patrick BF-TEM:** 299 paired training patches, 80 partially labeled validation images and 143 unlabeled test images. The 379 pairs are not all fully annotated evaluation data.
- **3D-SEM ceramic source:** a compressed NumPy array contains 1000 image/label pairs, with shape 2×1000×256×256×1. No two-dimensional samples are currently registered; a zero registered count does not indicate an empty upstream source.
- **TBM:** 320 crops and 32 full-image references. The existing project policy excludes this set from training.

## Storage and verification

Six canonical manifests passed relative-path and full-hash checks; six older manifests need format adaptation, and eight sets use registry/preparation records rather than a canonical manifest. Registered files were present and image/label dimensions matched. These are technical checks, not acceptance of segmentation quality or structure retention.

The five historical directories remain available locally for provenance; they are not automatically registered as new training sets. Local review decisions, splits, image bytes and annotation bytes were retained.
